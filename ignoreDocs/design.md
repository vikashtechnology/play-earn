# Design System

## Feel

Modern, trustworthy, minimal and reward-focused. Avoid casino/gambling
visual language.

## Tokens

-   Primary: #111827
-   Accent: #2563EB
-   Success: #16A34A
-   Warning: #D97706
-   Danger: #DC2626
-   Background: #F8FAFC
-   Surface: #FFFFFF
-   Text: #0F172A
-   Muted: #64748B
-   Border: #E2E8F0

## Typography

System sans/Roboto on Android; Inter/system sans on web admin.

## Spacing

8-point system: 4, 8, 16, 24, 32, 48.

## Components

Rounded cards, moderate radius, clear primary CTA, subtle borders,
limited shadows, consistent icons, skeleton loading and useful empty
states.

## Reward UX

Offer cards show reward, required action, completion condition, pending
status and restrictions. Wallet shows available, pending, lifetime
earned and recent transactions.

## Accessibility

Large touch targets, adequate contrast, content descriptions, no
color-only status and font scaling support.

## Consistency

No random UI changes between tasks.
